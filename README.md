
# 🍬 Nassau Candy Distributor Dashboard

## 📌 Project Overview

The Nassau Candy Distributor Dashboard is an interactive Business Intelligence dashboard developed using Python, Streamlit, Pandas, and Plotly.

It helps analyze sales performance, shipping routes, regional distribution, product performance, customer insights, and business KPIs through interactive visualizations.

---

## 🚀 Features

- 📅 Interactive Date Range Filter
- 🌍 Region Filter
- 📦 Division Filter
- 🚚 Ship Mode Filter
- 💰 KPI Cards
- 📈 Monthly Sales Trend
- 💵 Monthly Profit Trend
- 🌎 Sales by Region
- 📍 Sales by State
- 🗺️ USA Sales Map
- 🥧 Sales by Division
- 🚚 Ship Mode Analysis
- 🍫 Top 10 Products
- 👤 Top 10 Customers
- 📥 Download Filtered Data (CSV & Excel)

## ▶️ How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run dashboard.py
```
